# sofia-brain

Memória persistente da Sofia. O Samuel apaga as conversas ao fim de cada sessão, então
**tudo que precisa ser lembrado tem que estar escrito aqui**.

| Arquivo | Conteúdo | Quando atualizar |
|---|---|---|
| `perfil.md` | Quem é o Samuel, como ele usa o Claude | Ao aprender algo novo sobre ele |
| `regras.md` | Como trabalhar com ele, limites | Quando ele pedir ou corrigir algo |
| `objetivos.md` | O que ele quer alcançar | Quando mudar |
| `projetos.md` | Índice e estado de cada projeto | A cada entrega |
| `historico/AAAA-MM-DD.md` | Diário de cada sessão | Ao fim de cada sessão |
| `notas.md` | Anotações soltas, ideias, coisas a lembrar | Quando surgir |

Regras da memória:
- Não registrar nada da conta do Enzo (dono da conta). Só o que vem do Samuel.
- Datas sempre absolutas (2026-11-08, não "ontem").
- Preferir acrescentar a reescrever. Se algo ficar obsoleto, marcar como tal.
